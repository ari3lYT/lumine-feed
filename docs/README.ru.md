# Lumine Feed

Серверный Fabric-мод: игроки могут кормить друг друга, а получатель отдельно разрешает еду с эффектами.
Собери `./gradlew build`, установи основной JAR и Fabric API на сервер Minecraft 26.3 / Java 25.

`/feedtoggle effects on` разрешает еду с эффектами; `off` запрещает. `/feed` и `/heal` предназначены
для операторов. D2Gate необязателен. Перед рабочим сервером проверь кормление двумя игроками
на тестовой копии: автоматические тесты не заменяют проверку взаимодействия в игре.
