# Команды и файлы

| Команда | Права и поведение |
| --- | --- |
| `/feedtoggle` | Получатель переключает согласие на еду с эффектами |
| `/feedtoggle status` | Показать текущее согласие |
| `/feedtoggle effects on` | Разрешить еду с эффектами |
| `/feedtoggle effects off` | Запретить еду с эффектами |
| `/feedtoggle effects toggle` | Переключить согласие |
| `/feed [player]` | Игрок с OP или консоль с правами владельца и явно заданной целью |
| `/heal [player]` | Те же права; восстановить здоровье и сытость, убрать эффекты и огонь |

Файлы создаются в `config/lumine-feed/`: `player-prefs.properties` содержит предпочтения UUID получателей, `messages.properties` — редактируемые сообщения. Это рабочие данные, их не следует добавлять в коммиты как примеры. Стандартные сообщения — на русском. Остановите сервер перед редактированием файлов.

Специальный мод авторизации не требуется. Если установлен D2Gate, оператор дополнительно должен пройти проверку разблокировки. При недоступной или несовместимой установленной интеграции доступ закрывается.
